# CSE 4095 Individual Assignment: Web-Based Hangman Game

## Working assignment summary

This summary is taken from the Codex prompt queue supplied for the project. The original software specification is preserved separately in `SPECIFICATION.md`.

Build an original web-based Hangman game with:

- a Python Hangman game engine;
- three difficulty levels;
- a Flask REST API;
- an HTML, CSS, and JavaScript browser interface;
- automated tests;
- a repository in the student's own GitHub account;
- a publicly accessible HTTPS deployment on Render;
- a 1–2 page PDF development report; and
- an approximately 2–3 minute demonstration recording.

The deadline stated in the supplied queue is **October 29, 2026 at 11:59 PM Eastern**.

## Required submission items

- Own GitHub repository URL, accessible to the grader.
- Own public Render HTTPS application URL.
- 1–2 page PDF report with 2–3 representative prompts actually used.
- Approximately 2–3 minute screen recording showing a full game, restart, and an actual API request and JSON response.
- Complete source project, including the original specification, revised TODO, README, word lists, tests, and deployment configuration.
- Public application kept accessible during grading.

## Scope clarification supplied with the queue

The assignment is narrower than the original instructor specification. A terminal client, automated bots, bot evaluation, scoring, leaderboards, anti-cheating infrastructure, replay features, and the instructor's existing implementation are not part of this student's project.
